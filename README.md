mima OS — 26.2- ALPHA-RELEASE (WIP)
-----------------------------------
mima OS (mima 26.2) is a lightweight, web-based virtual desktop playground and compositor 
inspired by hyprland tiling layouts and cachyos / arch linux aesthetics. 

key features:
• true refractive liquid glass UI engine with dynamic backdrop blurring and specular highlights
• built-in pure white fastfetch terminal with custom CLI commands
• interactive desktop widgets & live cava audio visualizer
• complete session manager with user auth lock screen & custom hotkey shortcuts
• zero-asset web audio API synthesizer for tactile UI click & pop sound effects

And more to come soon.
